# Juno

Juno is a modern web-based IDE for J accessible at [https://jsoftware.github.io/juno/app/](https://jsoftware.github.io/juno/app/). It runs entirely in the user's browser using WebAssembly to run J interpreter, ensuring privacy.

Information about releases and new features is posted on the [J forum](https://groups.google.com/a/jsoftware.com/g/forum). It is also a great place to ask questions, post feature requests and report bugs. If you're not subscribed to the forum, please create a GitHub Issue instead.

Happy coding!
